ARCH_VISUAL 새 홈페이지 — 초보자용 안내
===================================

1. 이 압축파일을 다운로드 후 압축 해제하세요.
2. index.html 파일을 더블클릭하면 브라우저에서 시안을 볼 수 있습니다.
3. 이 버전은 HOME / ABOUT / WORK / CONTACT 화면과 이미지 확대가 작동합니다.
4. 작품 이미지는 기존 Wix 사이트의 공개 이미지 주소를 임시로 연결했습니다.
   따라서 인터넷 연결이 필요하며, Wix에서 이미지 링크가 바뀌면 표시되지 않을 수 있습니다.
   정식 이전 전에 보유한 원본 JPG 파일을 넣고 연결 주소를 바꾸는 것을 추천합니다.
5. CONTACT의 문의는 메일 앱을 여는 방식입니다. 실제 웹 입력폼 전송은 아직 없습니다.

[무료 사이트 공개 — 도메인 변경 전 테스트]
A. https://dash.cloudflare.com/ 에 무료 가입
B. Workers & Pages → Create → Pages → Direct Upload 메뉴 선택
C. 압축을 풀어 나온 archvisual_site 폴더의 내용 전체를 업로드
   (index.html, style.css, script.js 파일이 최상위에 있어야 합니다)
D. 임시로 제공되는 pages.dev 주소에서 확인
E. 잘 동작하는 것을 확인한 뒤 기존 archvisual.org 도메인 연결
   ※ 도메인/DNS/이메일 설정을 확인하기 전에는 기존 Wix를 해지하지 마세요.

[작품 이미지 교체]
- 원본 JPG들을 준비해두면 다음 단계에서 이미지 연결을 바꿀 수 있습니다.
- 작업 파일: script.js 상단의 ids/images 부분
- 현재 이미지 URL을 Wix 서버에서 가져오는 임시 방식이므로 완전한 독립 호스팅은 아닙니다.

[비용]
- 정적 사이트를 Cloudflare Pages의 무료 한도에서 운영할 경우 호스팅비 0원 가능.
- 도메인 갱신 비용 별도.
- 작업 대행, 유료 이메일 또는 별도 문의폼 서비스 필요 시 비용 추가 가능.

[주의]
- 현재 제작물은 구조와 스타일을 유사하게 재구성한 첫 시안이지 원본과 픽셀 단위로 동일한 복제본은 아닙니다.
- 기존 저작물과 이미지에 대한 이용권한이 있다는 전제입니다.
